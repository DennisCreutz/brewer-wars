Mit diesen Karten sollen besondere Herausforderungen für den Bau von MTG-Decks geschaffen werden, um herauszufinden, wer der beste Deckbauer ist.

Jede Karte besteht aus mindestens einem Effekt, einem Effektziel und einem Modifikator.
Ein Effekt bestimmt dabei welche Eigenschaften oder Einschränkungen ein Deck oder ein Commander (das Effektziel) erfüllen muss. Ein Modifier legt die Gültigkeit der Karte fest.
Es gibt 3 Arten von Modifikatoren: Global, Personal und Score.
Global-Karten haben Effekte, die alle Spieler betreffen. Personal betrifft nur den Spieler, der die Karte gezogen hat und Score bestimmt, nach welchen Kategorien gewertet wird.
Zusätzlich kann eine Karte noch optional einen Typ haben. Karten mit dem gleichen Modifier und Type können nicht gleichzeitig aktiv sein.

Ablauf:
Zunächst werden zwei Karten vom globalen Modifikatorenstapel gezogen. Diese Karten gelten für alle Spieler.
Danach werden drei Karten aus dem Score-Modifier-Deck gezogen. Sie legen die Wertungskriterien für dieses Spiel fest. Neben diesen modularen Wertungskriterien gibt es immer die Standardwertung von „+2 Punkte für den Sieger”.
Jeder Spieler muss am Ende des Spiels einem Spieler einen Punkt zuordnen, von dem er glaubt, dass dieser das meiste „Deckbaugeschick” gezeigt hat.
Zuletzt zieht jeder Spieler zwei Karten aus dem „Personal Modifiers Deck”. Diese sind nur für diesen Spieler gültig.

Wichtig: Wird eine Karte gezogen, die vom gleichen Modifikator und Typ ist, wird diese Karte abgelegt und eine neue gezogen.
Karten vom Typ "Solo" können nur der einzige Modifikator sein. Ist eine Karte vom Typ "Solo" die erste Karte die gezogen wird, werden keine weiteren Karten mehr gezogen.
Wenn eine Karte vom Typ "Solo" nicht die erste gezogene Karte ist, wird diese Karte abgelegt und eine neue Karte gezogen.
